# Sweetgrass

Visual developer workspace for [Beads CLI](https://github.com/gastownhall/beads)
projects.

Sweetgrass is Palmetto Interactive's heavily extended fork and continuation of
the MIT-licensed Beads Kanban UI. It adds a multi-project dashboard, GitOps
workflow, epic and related-task views, Beads memory editing, agent definition
management, and Rust-backed release packaging.

## Installation

```bash
npm install -g sweetgrass
```

## Usage

```bash
sweetgrass
```

The packaged server starts on port 3008 and opens your browser.

The legacy `bead-kanban` command is still included as an alias.

## Requirements

- Node.js 20 or higher
- [Beads CLI](https://github.com/gastownhall/beads) installed and configured

## Supported Platforms

- macOS (Apple Silicon and Intel)
- Linux x64
- Windows x64
